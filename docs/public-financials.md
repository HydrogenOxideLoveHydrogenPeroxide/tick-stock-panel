# 公开财务与分红数据

财务数据默认使用 `FINANCIAL_DATA_PROVIDER=eastmoney`，不要求 TickFlow
Expert。行情仍沿用项目现有 TickFlow 适配。可设为 `tickflow` 恢复官方财务接口。

在「财务分析」点击「全部同步」：依次同步核心指标、利润表、资产负债表、
现金流量表，再采集菜场大妈当前收盘快照。也可单独同步利润表后点击
「同步分红筛选快照」。任务在后台运行；失败原因显示在页面，旧数据保留。
公开来源可能限流/变更，项目设有超时、重试、大小/分页上限，禁止执行 JSONP/JS。

字段名校验，不依赖返回列顺序，不下载/执行远程代码。

分红为 `RPT_SHAREBONUS_DET`。缺少的科目保留 null，不用其他科目猜测替代。
金额单位为人民币元，ROE/增长率/毛利率为百分点，利润与现金流为年初累计。

## 时间与数据口径

财务同步取得每类最新报告期的全市场可用记录。后续同步保留旧报告期、替换
同一期当前修订值，并将每批原始标准化观测归档在
`data/financials/archives/`。每张表旁 `.source.json` 保存来源、采集时间及局限。
这不是历史 PIT 原始版本库；披露日期不等于我们实际取得该版本的日期。

菜场大妈 `ai_mwum51zl` 仅支持采集当日的当前收盘筛选：

- 当日沪深主板名单、已公布且归母净利润为正的最新利润表。
- 按除权除息日过滤过去12个月内已实施方案，预案、未来实施方案排除。
- 现金分红元/10股先除10，再按窗口内后续送转比例换算每股金额。
- 腾讯字段45提供当前总市值（亿元）；同时点市值/价格推导当前股本，
  不冒充历史股本。股价、上市天数等缺失时不默认为合格。
- ST/退市整理按当日名称识别，无成交股票保守剔除；它们不构成历史状态库。
- 上市交易日来自已有上证综指（000001.SH）交易日期，窗口内计数为老股票天数下界；
  至少250个交易日且覆盖当日才可验证门槛。
- 盘中不将最新价冒充收盘价；15:10后、报价日期与交易日历一致时才生成快照。

快照独立保存于 `data/fundamentals/dividend_screen/`，不会将今日数据并入历史
K线。当前快照读取器拒绝历史日期和过期数据。下述历史重建研究使用独立归档和月度组合
撮合，不以今日快照生成过去收益；当前候选列表本身仍不是历史回测结果。

## 命令行

在 backend 环境中执行 `python scripts/sync_public_financials.py --table all`。
可选 `--table income` 或 `--table dividend_screen`，以及 `--data-dir /path/to/data`。

代码和测试可提交 GitHub；运行数据、密钥、cookies、.env、SSH 文件、备份不得提交。


## 月度历史重建研究（新增）

当前收盘快照仍然不能用于历史回测。历史回测使用独立归档和专门的月度撮合，
不是移除原先的快照安全检查。默认研究区间2021-01-01至2026-11-24。

在 backend 环境安装研究依赖（`pip install -e '.[research]'`），然后显式执行：

```bash
python scripts/backtest_dividend.py --stage all --start 2021-01-01 --end 2026-11-24
```

同一目录冻结起止日期，更换区间请另指定`--folder`，防止复用不覆盖新日期的缓存。
采集可断点续传。`--stage collect`只采集；`--stage finalize`从已有历史候选/股本
继续核验状态及补齐派发日；`--stage run`只从已完成且指纹匹配的归档计算报告。
默认文件在 `data/research/dividend_backtest_2021/`，不提交Git。

历史数据来源：BaoStock 0.9.4的不复权行情、历史ST/交易状态、上市/退市日期、
分红派发日及送股上市日；巨潮 `p_stock2215` 的股本变动和公告日期；东方财富
历史财报和分红记录。巨潮时间戳加密协议参考同一AKShare固定版本的
`akshare/stock/finance/stock_share_changes_cninfo.py`及`akshare/data/cninfo.js`，
采用OpenSSL AES-CBC实现，不执行下载的JavaScript。F003N单位为万股。

历史分红股票并集只用于减少数据下载；每个时点仍只按此前已实施的分红筛选。
股票池包含后来退市的公司，不能用今天的上市状态排除过去的股票。首先使用
不复权月末价格粗筛与股本排序，再按市值顺序逐只核验对应日的ST/停牌状态；
若不足20只合格股票就继续核验后续名次。这与遍历全部候选后选前20只等价。

时点股本要求公告日和生效日均不晚于信号日；后披露的旧季度股本不能覆盖更近
日期已经公开的股本变动。财报按实际公告日期筛选最新报告期，并统计来源更新
日晚于信号日的记录。**来源为当前修订版，未逐份核验原始公告，研究结果不能
标为严格PIT认证。**

组合每月第一个交易日开盘调仓，依据上一个交易日收盘选股，按前收盘净值的
1/N分配预算。不融资、整手买入；开盘涨停不买、跌停或停牌不强行卖，旧持仓
退出订单延后重试；被阻买入的资金留至下一次月度调仓。成交量容量上限为此前
最多20个有成交交易日均量的5%，最少5天预热。现金分红按登记日持仓确认，
除权日列为应收，派发后才可买股；送股上市前不可卖出。使用不复权价，不重复
计入分红。现金分红采用统一20%保守计提税率，并另算税前对照；未逐笔模拟
持有期限税率、送股税或配股参与。

标准研究：初始10万元，选10只，佣金万3/最低5元，单边滑点5bp；另算100万元
容量、20bp滑点和现金分红税前情景。印花税和过户费随政策日期变化。政策参考：
[财政部2023年印花税公告](https://www.mof.gov.cn/jrttts/202308/t20230828_3904235.htm)、
[中国结算收费表](https://www.chinaclear.cn/zdjs/editor_file/20220701154723234.pdf)。

回测页面选择同一个`ai_mwum51zl`，使用持仓模式、次日开盘、全市场、等权；
历史研究文件准备完成后可运行。当前冻结档案的股息率固定3%，持仓数量支持
5～20；其他阈值需要重新准备档案，不能静默用旧候选代替。报告和逐笔委托在
`/api/financials/dividend-backtest/files/index.html`，所有接口沿用面板访问认证。


### 退市源修正

复核发现东方财富上述分红/财报列表默认不覆盖已退市公司，不能仅凭历史报表
日期便声称没有幸存者偏差。采集器额外检查研究区间内所有主板退市公司，使用
BaoStock历史分红补齐；当前研究检查176家公司，其中50家有历史现金分红。
缺退市补查标记的旧归档会被拒绝，不能继续显示为完整研究。

对巨潮不返回历史记录的12家退市公司，股本取BaoStock季报`totalShare`，单位为
股，并以`pubDate`为可用日、`statDate`为期末日。这不等于已重建期内每一次股本
变动，属于额外数据限制。缺归母利润的退市候选不能假定盈利：仅当按市值排序
确认它们在已经核验的前20名之后时，才可证明不会影响取前10；否则停止，必须
补数据。主回测未使用BaoStock通用`netProfit`替代归母利润。
